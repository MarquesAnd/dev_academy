🎨 O que é CSS — e as 3 formas de conectar

CSS = Cascading Style Sheets, as folhas de estilo. Se o HTML diz O QUE cada coisa É ("isto é um título"), o CSS diz COMO ela FICA ("títulos são roxos, grandes e centralizados"). São dois idiomas parceiros — e há três jeitos de apresentá-los:

FormaComoVeredito
Inline<p style="color:red">Quebra-galho. Espalha estilo pelo HTML — vira bagunça rápido
Interna<style>...</style> no headÓtima para aprender e para páginas de arquivo único
Externa<link rel="stylesheet" href="estilo.css">👑 A profissional: um arquivo .css veste o site INTEIRO
✱
Bem-vindo(a) de volta! Neste curso vamos usar a forma interna nos playgrounds (tudo num quadro só) — mas guarde: em projeto de verdade, o estilo mora num arquivo separado. Um lugar para mudar, o site inteiro obedece. É o mesmo princípio que salva sistemas grandes.
💡 O nome faz sentido
"Cascading" = em cascata: os estilos escorrem de cima para baixo e podem ser sobrescritos por regras mais específicas. Essa cascata tem regras de quem-ganha-de-quem — e no Módulo 8 você vira juiz dessa briga.

🔤 font-size e font-family: tamanho e voz

A tipografia é 90% do design de um site de conteúdo. As duas alavancas principais:

tamanho e família
body {
  font-size: 18px;
  font-family: 'Segoe UI', Arial, sans-serif;
}

O font-family é uma fila de espera: o navegador tenta a primeira fonte; não tem? Tenta a segunda; no fim, o plano C genérico (sans-serif = sem serifa, serif = com os pezinhos, monospace = de máquina). Sempre termine com um genérico — é o paraquedas.

💡 px vs rem, versão simples
px = tamanho fixo. rem = múltiplo do tamanho-base do navegador (1rem ≈ 16px por padrão) — respeita quem aumentou a letra nas configurações por precisar enxergar melhor. Aprenda com px, migre pra rem quando pegar o jeito; no Módulo 8 fechamos essa conta.

📏 width, max-width e a linha que salva vidas

Tamanhos: width e height você já intui. O herói escondido é o max-width: "cresça, mas até um limite". A receita de ouro do conteúdo legível:

a coluna de leitura perfeita
.conteudo {
  max-width: 700px;   /* nunca larga demais (linhas km não se leem) */
  margin: 0 auto;      /* 0 em cima, AUTO dos lados = centralizada! */
}

E a linha salva-vidas prometida — cole no topo de TODO projeto seu, para sempre:

o pacto de paz com a matemática
* { box-sizing: border-box; }

Tradução: "quando eu disser width: 300px, é o TOTAL — já contando padding e borda". Sem isso, width é só o recheio, e padding+borda vão SOMANDO por fora... e as caixas nunca cabem onde você calculou. (O * é o seletor-estrela: mira em tudo. E sim, esta escola usa exatamente essa linha.)

✱
Gerações de iniciantes sofreram com caixas transbordando 20px misteriosos antes dessa linha virar padrão. Você acabou de pular uns 3 anos de sofrimento coletivo em 10 segundos de leitura. De nada. 😄

🥞 z-index e overflow: pilhas e transbordos

Dois ajustes finos de quem posiciona coisas:

PropriedadeResolve

o pai organiza, os filhos obedecem

↕️ align-items — e o Santo Graal da centralização

Se justify-content trabalha AO LONGO da fila, align-items alinha no eixo CRUZADO (na fila horizontal: em cima/meio/embaixo). Valores: stretch (estica, padrão), flex-start, center, flex-end.

E juntando os dois eixos no centro... 🏆 a receita mais famosa do CSS moderno, a resposta definitiva ao "como centralizo isso":

O SANTO GRAAL — centralização perfeita em 3 linhas
.centro {
  display: flex;
  justify-content: center;   /* meio na horizontal */
  align-items: center;       /* meio na vertical */
}

🏙️ display: grid — a planta em colunas

Se flexbox é a FILA (uma dimensão), grid é a PLANTA (duas dimensões: linhas E colunas de uma vez). Você desenha as colunas no pai, e os filhos vão preenchendo as celas:

a grade nasce no pai
.grade {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;  /* 3 colunas de fração igual */
  gap: 12px;
}

O fr (fraction) é a unidade-estrela: divide a sobra em frações. 2fr 1fr = a primeira coluna com o dobro da segunda. E repeat(3, 1fr) é o atalho para "1fr 1fr 1fr".

⚖️ Flexbox ou Grid? O guia definitivo

A dúvida eterna, resolvida com uma pergunta: é uma FILA ou é uma PLANTA?

SituaçãoFerramentaPor quê
Navbar (logo + menu)FlexUma fila horizontal
Galeria/vitrine de cardsGridLinhas E colunas alinhadas
Botões lado a ladoFlexFila curta
Layout da página inteira (menu lateral + conteúdo)GridÉ literalmente uma planta
Centralizar uma coisaFlexO Santo Graal de 3 linhas

E os dois se combinam o tempo todo: um grid de página com navbars flex dentro. Não é rivalidade, é dupla — martelo e chave de fenda.

🌊 transition: a suavidade dos profissionais

O hover da lição passada TELETRANSPORTA de um estilo pro outro — funcional, mas seco. A transition faz a mudança ESCORRER:

uma linha, outra categoria de site
.botao {
  transition: all 0.3s ease;   /* o quê | duração | ritmo */
}

Vai no estado NORMAL (não no :hover!) — assim ela suaviza a ida E a volta. Durações: 0.15s–0.3s pra interação (mais que 0.5s parece site lento).

🎬 @keyframes e animation: o cinema do CSS

Transition precisa de um gatilho (hover). A animation roda SOZINHA, seguindo um roteiro de cenas chamado @keyframes:

roteiro + escalação
@keyframes girar {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}
.carregando {
  animation: girar 1.5s linear infinite;
}         /* roteiro | duração | ritmo | repete */

📐 Unidades elásticas: %, rem, vw e vh

Pixel é fixo — e telas variam de relógio a telão. As unidades elásticas se adaptam:

UnidadeRelativa a...Uso típico
%o tamanho do PAIwidth: 100% — imagem que preenche a coluna
rema fonte-base do navegador (~16px)fontes e espaçamentos que respeitam o usuário
vw / vha largura/altura da JANELAheight: 100vh — seção que ocupa a tela inteira (todo hero de landing page)
o trio elástico em ação
.hero   { height: 100vh; }        /* a tela cheia de boas-vindas */
img     { max-width: 100%; }      /* imagem NUNCA vaza da coluna — decore isto */
h1      { font-size: 2.5rem; }    /* 2.5× a base = ~40px, mas elástico */
💡 A linha que domestica imagens
img { max-width: 100%; height: auto; } — cole em todo projeto. É o cinto de segurança que impede fotos gigantes de explodirem o layout no celular.

📱 @media: o site que se adapta ao celular

A media query é um SE do CSS: "SE a tela for menor que X, aplique estas regras por cima":

o site camaleão
.galeria { display: grid; grid-template-columns: repeat(3, 1fr); }

@media (max-width: 640px) {   /* telas de até 640px (celulares)... */
  .galeria { grid-template-columns: 1fr; }  /* ...viram UMA coluna */
}

Lembre-se da dupla obrigatória: a media query cuida do CSS, e a <meta viewport> (do curso de HTML!) avisa o celular para usar a largura real. Uma sem a outra não funciona.

🎨 Variáveis CSS: o cofre de cores

Repetir #7C4DFF em 40 lugares e o cliente pedir "muda o roxo"? Sem variáveis, é caça ao tesouro. Com elas, muda-se UMA linha:

declare no cofre, use em todo lugar
:root {                          /* o cofre global (a raiz da página) */
  --roxo: #7C4DFF;
  --respiro: 18px;
}
.card   { background: var(--roxo); padding: var(--respiro); }
.botao  { border-color: var(--roxo); }

🚨 Sobre o !important
Existe um botão nuclear: color: red !important; atropela a hierarquia inteira. E como toda arma nuclear: quem usa no dia a dia transforma o projeto num campo minado onde nada mais se sobrescreve. Entenda a cascata em vez de gritar com ela — important é para emergências raríssimas.
