☕ O que é Java — e por que ele está em todo lugar

Java nasceu em 1995 com uma promessa ousada: escreva uma vez, rode em qualquer lugar. O truque? Seu código não vira um programa preso a um sistema — vira bytecode, um idioma intermediário que uma máquina especial, a JVM (Java Virtual Machine), sabe executar. Onde tem JVM, seu programa roda: Windows, Mac, Linux, Android...

🎩 A cerimônia: class e main

No Java completo, nenhum código fica solto: tudo mora dentro de uma classe, e o programa começa por uma porta de entrada sagrada chamada main. É a "cerimônia" do Java:

o traje de gala completo
public class MeuPrograma {                    // a CLASSE: o prédio onde o código mora
    public static void main(String[] args) {  // o MAIN: a porta por onde tudo começa
        System.out.println("Começou por aqui!");
    }
}

Cada palavra tem razão de existir (public = visível, static = pronta sem criar objeto, void = não devolve nada, String[] args = argumentos) — e TODAS vão fazer sentido total até o Módulo 7. Por ora, memorize como um ritual: class abre o prédio, main abre a porta.

🔁 while: repita ENQUANTO for verdade

Computador não cansa — e o while é a ordem de repetir enquanto uma condição valer:

a anatomia do while
int contagem = 5;

    System.out.println(contagem);
    contagem--;                  // ...algo PRECISA mudar, senão nunca acaba!
}
System.out.println("🚀 Decolar!");

🏠 Escopo: onde cada variável existe

Uma variável nasce e morre dentro das chaves onde foi criada. Isso se chama escopo — e é proteção, não frescura:

cada um na sua casa
void metodoA() {
    int segredo = 42;      // vive SÓ aqui dentro
}
void metodoB() {
    System.out.println(segredo);   // 💥 ERRO! segredo não existe aqui
}

Quer que dois métodos compartilhem um valor? Passe por parâmetro e receba por return — a via oficial. É por isso que os métodos da lição passada recebiam e devolviam tudo: dados viajando às claras, sem variáveis-fantasma.
